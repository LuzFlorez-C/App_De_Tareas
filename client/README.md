# Gestor de Tareas

Aplicación web fullstack desarrollada con **HTML, CSS, JavaScript, Node.js, Express y MySQL**.  
Permite crear, listar, actualizar el estado y eliminar tareas, conectando el frontend con una base de datos MySQL mediante una API REST.

---

##  Características principales
- Crear nuevas tareas con título y descripción.
- Visualizar todas las tareas almacenadas.
- Cambiar el estado de cada tarea: **Pendiente → En progreso → Completada**.
- Eliminar tareas de forma permanente.
- Conexión estable entre frontend y backend.

---

##  Tecnologías utilizadas
| Capa | Herramientas |
|------|---------------|
| **Frontend** | HTML, CSS, JavaScript, Axios |
| **Backend** | Node.js, Express, CORS, dotenv |
| **Base de datos** | MySQL (con mysql2) |
